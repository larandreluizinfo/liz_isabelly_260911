# One Piece RPG — Batalha dos Piratas 🏴‍☠️

Jogo de RPG de luta por turnos com personagens de One Piece.

Jogue: https://larandreluizinfo.github.io/liz_isabelly_260911/

## Como jogar
1. Escolha seu pirata: Luffy 👒, Zoro ⚔️, Sanji 🦵 ou Nami 🌩️
2. Vença 5 chefes: Buggy 🤡 → Arlong 🦈 → Crocodile 🐊 → Enel ⚡ → Kaido 🐉
3. Ações: 👊 Ataque, ⚡ Especial (20 energia), 🛡️ Defender, 🍖 Comer carne (cura)

XP dá level up (vida cheia + carne extra). Vitória salva 🏆 no navegador.
